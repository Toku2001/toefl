
# 公共サービスについてのSpeakingSession

## 経験についての質問

Yes, I have.
I remember using ～ when I wanted to … .
It was a good experience because … .
In particular, I found it … .
For this reason, I think ～ is a good way to … .

## 解答例1

Yes, I have.
I remember using a public library when I wanted to study.
It was a good experience because I could use a quiet environment for free.
In particular, I found it very convenient.
For this reason, I think using public libraries is a good way to study effectively without spending money.

## どちらが好ましいか？という質問

I prefer ～ to ～.
I think ～ is a better option because ～.
In particular, I find it ～.
For example, ～.
For this reason, I think ～ is a good way to ～.

## 解答例2

I prefer using public facilities in person to using online public services for two reasons.

First, I can communicate directly with staff and get help when I have questions.
Second, I find it easier to understand information through face-to-face communication.
For example, when I visit a public library, I can ask staff for help if I need it.
For these reasons, I prefer using public facilities in person.

## アイデアに対して良いか悪いか？

I think ～ because ～.
For example, ～.
This is important because ～.
For this reason, I think ～.

## 解答例3

I think public facilities should be open to everyone because everyone should have equal access to public services.
For example, people from other areas may want to use public libraries to study.
This is important because everyone should have the same opportunities to learn, regardless of where they live.
For this reason, I think public facilities should be available to everyone.
